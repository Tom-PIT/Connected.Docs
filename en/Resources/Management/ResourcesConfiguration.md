# Resources configuration

Configure **Resources** settings that affect document numbering and behavior for resource-related documents.  Any changes are saved automatically.

To access this page, go to **Resources / Management / Configuration** in the [navigation](../../Common/UI/Navigation.md).

![Resources Configuration](../Images/ResourcesConfiguration.png)

## Travel orders

Configure numbering behavior for **Travel Orders** documents.

| Field | Description |
|------|-------------|
| **Document numbering model** | Defines how document numbers are generated. <br> • **Incremental for each year:** numbering restarts every calendar year. <br> • **Incremental:** numbering continues without resetting. |
| **Document code format** | Defines the structure of the generated document code. <br> Placeholders such as **{0:yyyy}** and **{1:D8}** are replaced automatically when a document is created. |

> [!TIP]
>
> Use a consistent document code format to make travel orders easier to identify and sort across years.
