# Restock or produce

This tutorial explains, in simple terms, what to do when you get a sales order and don’t have enough stock before delivery.

- You can buy more (resupply) — Order the missing goods from a supplier. Example: You sell pine tables and have 2 in stock but need 10. Create a **Supply Order** for 8 finished tables (or for wood, legs, screws if you assemble in‑house).
- Or you can produce more (make) — Build the missing goods with your own process. Example: You manufacture pine tables from wood and hardware. Create a **Production Order** for 8 tables and consume the needed materials.

> [!NOTE]
> Which option applies depends on your business model:
> - Trading company (buy/sell finished goods) → usually Buy
> - Manufacturer (you make the goods) → usually Produce (and buy raw materials if missing)
> - Services/software → usually neither (no stock to move)

> [!TIP]
> Before you start: ensure **[Processes](../Production/CodeLists/Processes.md)**, **[Inputs](../Production/CodeLists/Inputs.md)**, and **[Outputs](../Production/CodeLists/Outputs.md)** are defined.

## Detailed steps

### 1. Detect shortage

- Go to the published **Sales Order** and review ordered items, then open **[Stock](../Logistics/Documents/Stock.md)** to check current balances per warehouse/location.
- When creating an [**Issue**](../Logistics/Documents/Issues.md) document, for example, via **Linked Documents → + Full Issue**. If stock is insufficient, the system shows a warning and prevents you from continuing or publishing until quantities are available.
- In production, open **[Requirements](../Production/Documents/Requirements.md)** to see which materials or semi‑products are short for planned operations.

### 2. Decide: Resupply or Produce

- If you buy/sell finished goods → proceed with Resupply.
- If you manufacture goods → proceed with Produce (and Resupply raw materials/semi products as needed).

### 3. Resupply (buy)

3.1 (Optional) Send an Inquiry
- Go to **Supply / Documents / Inquiries**
- Use the [**action button**](../Common/UI/ActionButton.md) to create a draft [inquiry](../Supply/Documents/Inquiries.md)
- Add items, request price and lead time; Click **Publish** to send

3.2 Create a Supply Order
- From the Inquiry (or directly), open **Linked Documents → [+ Supply Order](../Supply/Documents/SupplyOrders.md)**
- Confirm supplier, items, and delivery date; Click **Publish**

3.3 Receive into stock
- In the Supply Order, open **Linked Documents → [+ Receive](../Logistics/Documents/Receives.md)**
- Select warehouse and locations, confirm received quantities; Click **Publish**
- (Optional) Verify balances in **[Stock](../Logistics/Documents/Stock.md)** or **[Stock View by Location](../Logistics/Views/StockViewByLocation.md)**

### 4. Produce (make)

> [!IMPORTANT]
> Ensure your process/operations exist in **[Processes](../Production/CodeLists/Processes.md)** with defined **[Inputs](../Production/CodeLists/Inputs.md)**/**[Outputs](../Production/CodeLists/Outputs.md)**.

4.1 Create a production order
- Go to **Production / Documents / Production Orders**
- Use the **[action button](../Common/UI/ActionButton.md)** to create a draft [production order](../Production/Documents/ProductionOrders.md)
- Select Product, Process, Quantity, Due date, Organization unit; Click **Publish** to commit
- Set Status to **Active** to make the order available in **[Execution](../Production/Documents/Execution.md)**

4.2 Resolve input shortages
- Open **[Requirements](../Production/Documents/Requirements.md)**
- Use the filter **Show planned operations** to see missing materials/semi-products for the production order
- For short inputs, use the **+** sign top create a new **[Supply order](../Supply/Documents/SupplyOrders.md)** and complete the [**Receive**](../Logistics/Documents/Receives.md) step (see 3.3)

4.3 Record execution

Use the **[Execution](../Production/Documents/Execution.md)** module to track production progress:

- Enter produced items via the **Produce** button
- Access the activity selection menu using the **[action button](../Common/UI/ActionButton.md)** to record:
  - **[Consumed](../Production/Documents/Consumed.md)** — materials used during production
  - **[Effort](../Production/Documents/Effort.md)** — labor time spent
  - **[Loss](../Production/CodeLists/LossClassificationTags.md)** — quantity scrapped and the reason (if any)
  - **[Downtime](../Production/Documents/Downtime.md)** — equipment stops and duration (if any)
- Save and review outputs; repeat until order is complete

### 5. Continue the sales flow

- Return to the **Sales Order** and follow the delivery/invoicing tutorials:
  - **[Sales process (with prepayment)](02.SalesProcessWithPrepayment.md)**
  - **[Sales process (without prepayment)](03.SalesProcessWithoutPrepayment.md)**

> [!TIP]
> After completion, you can review any details in the list of closed [**Production orders**](../Production/Documents/ProductionOrders.md).
