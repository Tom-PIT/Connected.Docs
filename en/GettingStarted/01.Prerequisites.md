# Prerequisites

Before running the scenarios, ensure core configuration and common code lists are in place. Follow these steps and use the linked docs for details.

## Prerequisites steps

### 1. Create essential Common code lists

These shared code lists are required by **[Sales](../Sales/Domain/SalesDomain.md)**, **[Supply](../Supply/Domain/SupplyDomain.md)**, **[Logistics](../Logistics/Domain/LogisticsDomain.md)**, **[Production](../Production/Domain/ProductionDomain.md)**, and **[System](../System/Settings/Configuration.md)**:

- **[Countries](../Common/CodeLists/Countries.md)**
- **[Currencies](../Common/CodeLists/Currencies.md)**
- **[Tax rates](../Common/CodeLists/TaxRates.md)**
- **[Measure units](../Common/CodeLists/MeasureUnits.md)**

> [!IMPORTANT]
>
> Common code lists must be created before selecting them in System configuration or domain documents. See **[Common domain](../Common/Domain/CommonDomain.md)** for details.

### 2. Configure System settings

Set the organization and global defaults used across all modules:
- **[System configuration](../System/Settings/Configuration.md)**
  - Configure Organization (identity, legal details, footer)
  - Set Common Types (default Country, default Currency)

### 3. Payment settings (for Sales)

If your scenarios include Sales documents, configure payment data:
- **[Payment methods](../Sales/CodeLists/PaymentMethods.md)**
- **[Organization bank accounts](../Sales/CodeLists/OrganizationBankAccounts.md)**

### 4. Business directory

Add business partners (customers, vendors, cooperators) to use them across procurement, sales, and logistics:
- **[Business directory](../Common/CodeLists/BusinessDirectory.md)**

### 5. Warehouse and locations (if applicable)

For logistics or production scenarios involving stock:
- **[Warehouses](../Logistics/CodeLists/Warehouses.md)**
- **[Locations](../Logistics/CodeLists/Locations.md)**
