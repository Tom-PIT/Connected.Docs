# Non-human resources

Non-human resources define **machines and equipment** used by operations. Assign them to operations to plan and record runtime and capacity.

To access this page, open a process version from **Production / Management / [Processes](Processes.md)**, click **[Operations](Operations.md)**, then select **Non-human resources** for the chosen operation.

![Non-human resources button](../Assets/NonHumanResourcesButton.png "Non-human resources button")

> [!TIP]
> For a full demonstration, see the **[Human and Non-human resources](https://www.youtube.com/watch?v=iq7fQiPh_i4)** video tutorial.

## Schema

| Field | Description |
|-------|-------------|
| **Entity** | Select a **Non-human resource** (machine/equipment). |
| **Time** | Expected runtime per batch/unit. |
| **Ordinal** | Display order. |
| **Tags** | Optional tags for grouping or filtering. |

## List view

Shows all non-human resources linked to the selected operation.

## Creating a new non-human resource entry

1. Click the **action button** and choose **New**.
2. Fill in the required fields.
3. Click **Add**.

## Editing

1. Click the entry in the list.
2. Adjust fields.
3. Click **Save**.

## Deletion

Click **Delete** on the Edit page.
