# Processes

Processes define **how products are made** by grouping operations into versions with clear inputs, outputs, and resources.

To access this page, go to **Production / Management / Processes**.

![Processes list](../Assets/ProcessesList.png "Processes list")

> [!TIP]
> For a full demonstration, see the **[Processes and versions](https://www.youtube.com/watch?v=4svpFCm7rkk)** video tutorial.

## Schema

| Field | Description |
|-------|-------------|
| **Name** | Process name. |
| **Code** | Auto-generated identifier. |
| **Description** | Optional description. |
| **Versions** | Manage versions and their operations. |
| **Tags** | Optional tags for grouping. |

## List view

Shows all processes with names and codes.

## Creating a new process

1. Click the **action button** and choose **New**.
2. Enter name and description.
3. Click **Add**.

## Editing

1. Click a process.
2. Modify fields.
3. Click **Save**.
