# Sales configuration

Configure **Sales** settings affecting document numbering. Any changes are saved automatically.

To access this page, go to **Sales / Management / Configuration** in the [**navigation**](../../Common/UI/Navigation.md).

![Sales Configuration](../Images/SalesConfiguration.png)

## Document numbering settings

Choose the numbering model and format for Sales documents (Offers, Sales orders, Delivery notes, Issued invoices, Credit notes, Debit notes).

| Field | Description |
|-------|-------------|
| **Document numbering model** | • **Incremental for each year:** sequence resets annually. <br> • **Incremental:** a global sequence that never resets.  |
| **Document code format** | Pattern defining structure (e.g., PREFIX‑YEAR-NUMBER). |
