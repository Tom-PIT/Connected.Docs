# Action button

The action button appears as a round blue **+** icon in the bottom-right corner of list pages.  
Its primary purpose is to create new records within the module you are viewing.

![Action button](../Images/ActionButton.png "Action button")

When clicked, the button opens a context menu with actions relevant to the current screen.  
The most common action is:

- **New** — create a new document, code list item, or configuration entry.

Depending on the module, the Action button may also include additional options, such as:

- **Import** — upload or import data from external files (e.g., Excel templates).  
- **Copy existing** — create a new item based on an existing one.  
- **Other module-specific actions** — shown only when applicable.

![Action button menu](../Images/ActionButtonOptions.png "Action button menu")

### Notes

- The available actions depend on the module and user permissions.  
- The Action button is only shown on **list pages**, not on document edit forms.  
- Each action opens or generates a **new draft record**, which can then be completed and published.
