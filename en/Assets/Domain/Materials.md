# Materials

Materials represent the operational items your organization uses in logistics, production, stock management, or assembly processes. They include finished products, partially produced items, raw inputs, and reusable components. Additional code lists help define packaging, measurement units, and bulk import functions.

To access Materials, go to **Assets / Materials** in the [navigation](../../Common/UI/Navigation.md).

![Assets domain overview](../Images/MaterialsSitemap.png "Assets domain overview")

## Material categories

The Materials section contains four primary code lists, which represent the main types of materials managed in operational workflows:

- **[Products](../Management/Products.md)** – Finished goods produced internally or purchased as ready-to-use items. Products participate in stock and logistics flows.
- **[Semi products](../Management/SemiProducts.md)** – Items that represent partially completed goods used as intermediate components in production.
- **[Raw materials](../Management/RawMaterials.md)** – Basic input materials used at the earliest stages of production, such as wood, metal sheets, or other fundamental components.
- **[Repro materials](../Management/ReproMaterials.md)** – Returnable or auxiliary components used to support production or internal activities.

![Materials Subdomain](../Images/MaterialsSubdomain.png "Materials subdomain")

## Additional material-related code lists

These code lists support the management and definition of the four primary material types:

- **[Packaging](../Management/Packaging.md)** – Defines how a material is packaged, including quantity, weight, dimensions, and optional alternative measure units.
- **[Import materials](../Management/ImportMaterials.md)** – Allows bulk importing of materials using a spreadsheet, useful when creating or updating multiple records at once.
- **[Alternative measure units](../Management/AlternativeMeasureUnits.md)** – Additional measurement units that extend a material’s base unit (e.g., pieces, kilograms, square meters), including conversion settings.
- **[Material price lists](../Management/MaterialPriceLists.md)** – Defines procurement prices used for purchasing and internal valuation.
- **[Sets](../Management/Sets.md)** – Predefined bundles of materials grouped together for easier selection in logistics or production tasks.
